# Курсы фотографии Анны Канаки

Тёмный лендинг онлайн-курсов фотографа Анны Канаки (стиль — её сайт annakanaki.wfolio.pro) с AI-ассистентом внизу страницы. Ассистент отвечает по документам из папки `knowledge/` (RAG) через Gemini.

- План и статус работ: [tasks.md](tasks.md)
- Правила для агента: [CLAUDE.md](CLAUDE.md)
- Скиллы дизайна: `.claude/skills/` (design-taste-frontend, frontend-design, unslop)

## Как менять тексты сайта

Все тексты, курсы, шаги обучения, вопросы и фото галереи — в Excel-таблице `content/site.xlsx`:

| Лист | Что там |
|---|---|
| Главная | заголовок, подзаголовок, текст об Анне, ссылки на Telegram и портфолио |
| Курсы | одна строка — один курс: название, для кого, уровень, длительность, формат, цена, фото |
| Шаги | как проходит обучение, по порядку |
| Вопросы | частые вопросы и ответы |
| Галерея | фото раздела «Работы Анны» и их описание для незрячих |

- Фото указываются именем файла из папки `public/photos` (например, `anna-06.jpg`). Новое фото — положите файл в эту папку и впишите имя в таблицу.
- Уровень курса — только «Новичок», «Средний» или «Продвинутый» (в ячейке выпадающий список).
- Названия листов и заголовки колонок не меняйте: по ним сайт находит данные. Если что-то не так, сборка остановится и напишет, какой лист и какая колонка.
- При `npm run dev` достаточно сохранить таблицу и обновить страницу. Для готового сайта — пересобрать (`npm run build`).

## AI-ассистент и база знаний

Ассистент отвечает только по файлам из папки `knowledge/` (`.md`, `.txt`, `.pdf`) через Gemini.

1. Получите ключ на https://aistudio.google.com/apikey и создайте в корне проекта файл `.env.local` с одной строкой:

   ```
   GEMINI_API_KEY=ваш_ключ
   ```

   Этот файл не попадает в git, ключ остаётся только у вас.
2. Положите материалы в `knowledge/`: программы курсов, ответы на частые вопросы, условия оплаты.
3. Постройте индекс (после каждого изменения файлов в `knowledge/`):

   ```bash
   npm run ingest
   ```

4. Перезапустите `npm run dev`.

Если индекс пустой, ассистент честно отвечает, что в базе нет материалов. Если ответа нет в файлах, говорит, что не знает, и предлагает написать Анне в Telegram.

## Как забрать проект на свой компьютер

Нужны [Git](https://git-scm.com/downloads) и [Node.js](https://nodejs.org/) версии 22 или новее.

```bash
git clone -b claude/stoic-franklin-wwsy1n https://github.com/aksenovvm/claudec1.git "D:\Мирослав\claudec1"
```

```bash
cd "D:\Мирослав\claudec1"
```

```bash
npm install
```

```bash
npm run dev
```

Сайт откроется на http://localhost:3000.

Обновить после новых шагов (если изменился `package.json`, `npm install` обязателен, иначе будет ошибка `Module not found`):

```bash
git pull
```

```bash
npm install
```
